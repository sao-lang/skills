# 经验条目格式

## 技能级 `lessons.md`

```markdown
# Lessons · <器官名>

- 触发：<什么信号出现> → 动作：<先做什么> → 依据：<overview 路径或原因>
- 触发：<什么信号出现> → 禁止：<不要做什么> → 替代：<改做什么>
```

## 项目级 `docs/conventions.md`

```markdown
# 项目约定

- 触发：<模块/目录/场景> → 约定：<必须怎么做> → 原因：<决策来源>
```

## 草稿格式（learn_capture.py 输出）

```markdown
## 本次 learn 回写（草稿，需人工确认）

- [触发条件] <候选条目> → [处理动作] 待补（来源：overview）
```

> 草稿绝不直接作为正式约定；必须人工确认后去掉"草稿"标记。
