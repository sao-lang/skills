# 独立 review 门禁 · 完整规则

> 用途：conductor 交付前的最后一道独立闸门。**凡涉及代码改动的场景，finish 前必须由全新上下文子代理跑一次独立 code-quality-review，Blocker 清零才准交付。**
> SKILL.md 只保留一句话指针 + 铁律第 6 条，完整规则在此；本文件由 S5 阶段加载。
> **档位裁切**：standard/full 走本文件全文；lite 档不派子代理，按 `cost-tiers.md` §4 写「轻量复核（lite）」章节并跑 `review_gate.py --lite`。升档后本节规则自动恢复。

## 起因与根因

项目反复出现"coding 收尾时自查说通过、用户单独叫一次自省却查出重大问题"。
根因是 S4 的自省由**写代码的执行者本人**完成（运动员当裁判），有确认偏误、只看 L1/L2 信号，
L3（功能遗漏 / 功能断点 / 接线断裂）靠自觉。本门禁把"交付前的深度自省"从执行者自查中剥离，
交给**独立上下文**，从机制上堵住。

## 触发范围（按"有无代码改动"判定，不按场景名）

| 触发 | 场景 | 说明 |
|---|---|---|
| ✅ 必须 | 1 初始化 / 4 开发 / 5 迭代 / 6 设计驱动重构 / 7 重构 / 8 解 bug | 改码路径，全部触发 |
| ✅ 必须 | 13 测试补课 | 写了测试代码，触发 |
| ✅ 已含 | 12 门禁验收 | 本就含全套 review，不重复派单但阻塞项必须清零 |
| ❌ 不触发 | 9 拷问 / 10 代码库理解 | 只读，无代码改动 |
| ❌ 不触发 | 2 架构设计 / 3 补充设计 / 11 文档同步 | 纯文档产出，无生产代码改动 |

## 执行方式（独立性是硬要求）

1. **派全新上下文子代理**：不带 coding 会话历史，只给它——
   (a) 设计规格 / 任务 brief 的路径（意图源），
   (b) 改动文件清单或 diff（`git diff <base>..HEAD`），
   (c) 报告写回位置——**主 overview 的 `## 独立 review 报告` 章节**（报告内嵌，不另建 .review.md）。**禁止让写代码的执行者自己审自己**。
2. **七维扫描**：按 `code-quality-review` 的七维（正确性/错误处理/并发/资源/性能/安全/可维护性）
   + 接线四问（`references/04-guards/architecture-contracts.md`）审；重点看**功能遗漏与功能断点**（L3），
   不只是代码风格。
3. **分级输出**：Blocker / Should / Nit（Nit ≤3），每条带 `文件:行号` + 后果 + 改法，
   写到 overview 的「独立 review 结果」一节。

## 通过标准与失败处理

- **通过**：Blocker = 0 → 可进入 finish。Should 建议修，Nit 可留。
- **失败**：有任一 Blocker → 触发 fix loop：主代理把 finding 交给执行者修（守 surgical changes），
  改完回到 S3 的验证步骤确认仍绿，**再派一次全新子代理复审**（禁止用同一份 review 报告复用作废结论）；
  直至 Blocker 清零或按轮次上限裁决并记入 overview。
- **证据**：主 overview 必须留——`## 独立 review 报告` 章节（内嵌完整报告，多轮用 `### Round N`）+ Blocker 清零结论 + 每轮 fix 的行号证据。**不生成独立 .review.md 文件**。
  拿不出 = 门禁未过。

## 机器强制

`scripts/review_gate.py --overview <path>` 自动核对上述证据——检查「独立 review 结果」章节、
Blocker 清零结论、以及 review 证据（内嵌报告章节有分级/证据，或外部报告文件真实存在——兼容旧文档）；任一缺失退出码非 0，
**禁止 finish / 标完成**。非改码场景（只读/纯文档）用 `--waived --waiver-reason "<理由>"`
显式豁免，禁止默默跳过。

## 与 S4 自查的分工（不要混淆）

- **S4 自查（执行者）**：跑脚本、拿退出码、缺口台账草稿、覆盖率证据——快、机械、L1/L2。
- **S5 独立 review（子代理）**：契约映射、接线、功能遗漏/断点、七维深审——慢、独立、L3。
- 两者**都要做，不可互相替代**。S4 过了不代表 S5 可省；S5 是交付前的最后一道独立闸门。
